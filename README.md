# Roomark

给每个桌面，一个名字。

Roomark 是一款正在开发的原生 macOS 软件，旨在让你为虚拟桌面设置自定义名称，并在 Mission Control 中直接看到它们。

## 为什么做 Roomark

当桌面越来越多，“桌面 1”“桌面 2”“桌面 3”很难让人一眼分清用途。Roomark 希望让这些工作空间拥有有意义的名字，例如“开发”“学习”“娱乐”，帮助你更快找到需要的桌面。

## 产品目标

- 为每个普通虚拟桌面设置、修改或清除自定义名称。
- 在 Mission Control 中对应的桌面名称位置显示名称。
- 在应用或系统重启后保留名称，并尽可能在桌面重新排序时保持正确对应。
- 保持免费、轻量，提供简单的原生 macOS 体验。

以上为计划实现的产品能力。名称将通过覆盖层进行视觉替换，不修改 macOS 内部的桌面名称。

## 开发状态

Roomark 仍在开发中，目前处于核心能力验证阶段，尚未提供正式版本。
